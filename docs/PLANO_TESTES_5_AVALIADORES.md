# Roteiro para testes de aceitação por cinco avaliadores

**Quando aplicar:** depois que o MVP estiver funcionando localmente ou em endereço publicado. Cada pessoa deve testar pessoalmente e registrar o que observou. **Não preencher dados de testes fictícios.**

## Instruções para o avaliador

1. Acesse o sistema pelo link informado pelo autor do projeto.
2. Faça login com credenciais de **teste** (nunca de empresa real).
3. Consulte a lista de não conformidades e aplique filtros.
4. Se tiver permissão, registre uma NC de exemplo e uma ação corretiva.
5. Atualize o status da ação e verifique o painel.
6. Comunique falhas, sugestões e funcionalidades não testadas.

## Campos mínimos por avaliador

- Nome (autorizado pelo avaliador):
- Data do teste:
- O que testou e funcionou:
- O que testou e não funcionou — o que deve ser corrigido:
- Funcionalidade não testada (ausente ou não implementada):
- Evidências (capturas de tela, sem informações sensíveis):

Repita o mesmo formulário para **cinco pessoas diferentes**. Após consolidar, acrescente ao laudo de qualidade: erro, severidade, causa provável, correção, teste de regressão e evidência.
